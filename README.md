# Учебный Task Manager на Vue 3

Минимальный пример Vue 3 + Vite на JavaScript. Вся логика и стили — в `src/App.vue`.

## Запуск

```sh
npm install
npm run dev
```

## Проверка сборки

```sh
npm run build
npm run preview
```

Возможности: добавление и удаление задач, отметка выполнения, фильтры All / Active / Completed, счётчик активных задач и сохранение в localStorage. Пустые названия не добавляются.
